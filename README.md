# Interactive Excel Sales Dashboard 📊

Welcome! This repository contains an interactive Excel Sales Dashboard that I built to analyze order-level sales data.

I created this project to practice transforming raw data into actionable visual insights using PivotTables, PivotCharts, Slicers, and Timelines in Microsoft Excel.

## 📸 Dashboard Preview

## 💡 Key Highlights & Features

* **KPI Summary Cards**:

  * **Total Revenue:** \$2.45M

  * **Total Orders:** 2,000

  * **Quantity Sold:** 5,552 units

  * **Average Order Value (AOV):** \$1.23K

* **Interactive Filtering**: Dynamic multi-chart filtering using slicers (**Region**, **Product Category**, **Sales Channel**, **Customer Type**) and timeline controls (**Years**, **Quarters**, **Months**, **Days**).

* **Visual Analytics**:

  * **Revenue Trend:** Monthly performance analysis throughout the year.

  * **Regional Breakdown:** Comparative performance across Central, East, North, South, and West regions.

  * **Category Analysis:** Top revenue drivers across product categories (e.g., Computers, Monitors, Accessories).

  * **Sales Channel Breakdown:** Revenue distribution across Corporate Sales, Marketplace, Online, and Retail Store.

  * **Top Products:** Bar chart ranking top 5 products by revenue (led by Gaming Laptop).

## 📁 Workbook Structure

The Excel file is structured to reflect a clean data analysis workflow:.

1. `Sales_Data`: Raw sales order dataset.

2. `Supporting_Pivots`: Backend PivotTables powering all dashboard visualizations and KPI blocks.

3. `Sales_Dashboard`: The final interactive visual dashboard.

## 🛠️ Tools & Skills Used

* **Tool:** Microsoft Excel

* **Techniques:** Data Analysis, PivotTables, PivotCharts, Slicers, Timeline Slicers, KPI Formatting, Layout & UI Design.

## 🚀 How to Explore This Project

1. Clone or download this repository:

   ```
   git clone https://github.com/xmeintoss-art/Excel_pivot_table_dashboard
   
   ```

2. Open the file `Excel_Sales_Dashboard.xlsx` in Microsoft Excel.

3. Switch to the **`Sales_Dashboard`** tab.

4. Interact with the slicers on the left and timeline controls at the top to filter the data dynamically.
